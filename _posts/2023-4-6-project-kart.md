WIP!!!!! This project goes off my Cita 312 final, which was a unity kart racer, as well as my first exposure to unity's networking system for games.

The game is a simple flat kart racer, that you create a server for, and have clients join that server to face eachother. This took me a very long time as unitys official multiplayer networking tools were brand new at the time and had subpar documentation. Despite that, it was still a fun experience, and it was especailly cool to have the whole class play my kart racer.

again VERY WIP
